# doc-architecture

Архитектура как данные: YAML по единице является источником, а `ARCHITECTURE-SPINE.md` собирается из него. Совместимо с BMad Method.

| Путь | Что внутри |
| --- | --- |
| `tools/arch.py` | `split`, `build`, `check`, `unit`, `pack` |
| `schemas/` | Схемы решений, компонентов, блоков, интерфейсов, хранилищ, параметров, FMEA и сценариев качества |
| `skills/doc-arch/` | Навык для агента |

`split` записывает файлы, только если сборка из них совпала со Spine побайтно. `check` проверяет схемы и ловит ручную правку Spine.

## Зачем

На истории 1.1 примера пакет из YAML стоит около 4,8 тысячи токенов против 7,6 тысячи при полном Spine, находки сопоставимы. Замеры находятся в `doc-rules`.
